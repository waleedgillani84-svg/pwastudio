# PWA Studio — Progressive Web App

Offline-capable PWA ready for **GitHub Pages**.

## 🚀 Deploy on GitHub Pages

1. Create a new repository on GitHub.
2. Upload these files to the root:
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `README.md`
   - `icon-192.png`
   - `icon-512.png`
3. Go to **Settings → Pages**.
4. Under **Branch**, select `main` and `/ (root)`.
5. Save. Your app will be live at:  
   `https://<username>.github.io/<repo>/`

## 📱 Install on Phone

- **Android Chrome:** Open the link → tap menu → "Add to Home screen".
- **iOS Safari:** Open the link → tap Share → "Add to Home Screen".
